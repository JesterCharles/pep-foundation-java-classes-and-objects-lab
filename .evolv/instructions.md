# Classes and Objects — Code lab

Model a help-desk ticket as a class that can never be put into an invalid state: constructors and validation, encapsulation, enums, `toString`, equality and `StringBuilder`.

- **Edit:** `Ticket.java` and `Priority.java` in `src/main/java/exercise/`. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 7 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: `README.md` in the project folder.
